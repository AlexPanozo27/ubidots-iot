1 · La idea

¿Qué es Ubidots?

Ubidots es una plataforma de desarrollo de Internet de las Cosas (IoT). Sirve para que estudiantes, emprendedores, integradores y empresas lancen proyectos IoT sin tener que contratar un equipo de software: tú mandas los datos y Ubidots los guarda, los muestra y reacciona.

STEM

Para aprender

Nivel gratuito pensado para makers, estudiantes, investigadores y aficionados que están descubriendo el IoT. Es el que usarías en la universidad.

Cloud

Para proyectos

La oferta principal de Ubidots, entregada como servicio en la nube, para llevar un proyecto a producción.

Enterprise

Para volumen

Soporte dedicado, acuerdos de servicio y mucho volumen de dispositivos o datos. Puede incluir una nube privada.

2 · Las piezas

Dispositivos, variables y dots

Todo en Ubidots gira alrededor de tres cosas: el dispositivo que envía, la variable que guarda y el dot, que es cada dato con su hora.

Device

Dispositivo

Una entidad virtual con un label único (el que usas en el código) y un nombre para humanos. Lo recomendable es un dispositivo de Ubidots por cada dispositivo físico.

Variable

Variable

Guarda los dots de un dispositivo, como temperatura o humedad. Las default traen datos crudos y las sintéticas se calculan con fórmulas.

Dot

Dot

Cada dato que llega. Tiene value (número), timestamp (milisegundos, opcional) y context (pares clave-valor, hasta 1 KB).

Token

Token

La llave que acompaña cada petición. Dice quién eres y a qué cuenta pertenece el dato. Se trata como una contraseña.

Dashboard

Dashboard y widgets

Tableros arrastrar y soltar con métricas, gráficas de líneas, tablas, mapas, interruptores de control e incidentes.

Event

Evento

Una regla que, al cumplirse, avisa por correo, SMS, Slack, Telegram o voz, o ejecuta un webhook, una función o cambia una variable.

  4 · Conexión
  
      Cómo habla tu dispositivo con Ubidots
      
  
      Ubidots acepta datos por HTTP (REST) y por MQTT. Rellena los datos de tu dispositivo y el código se arma solo. El token de esta página es de mentira: nunca publiques el tuyo.

      Generador de código
      
    
      
      
      
      
      
    
      
    
      
      
      
      
    
      
    
      
    
        
  
        

  
        
    
        HTTP
        REST
        Se envía un POST a industrial.api.ubidots.com/api/v1.6/devices/<label>/ con la cabecera X-Auth-Token y un JSON. Va bien cuando envías cada tanto.
        
    
        MQTT
        Broker de Ubidots
        Servidor industrial.api.ubidots.com, puerto 1883. Usuario: tu token. Contraseña: vacía. Sirve también para recibir órdenes.
        
  
        

  
        Qué soporta y qué no el broker compartido
        
  
        
    
        TemaQué pasa
        
    
      
        Publicar una variable/v1.6/devices/{device}/{variable} con {"value":10}
        
      
        Publicar varias/v1.6/devices/{device} con {"temperatura":10,"humedad":50}
        
      
        Leer el último valorSuscribirse a /v1.6/devices/{device}/{variable}/lv entrega solo un número, fácil para un microcontrolador
        
      
        MayúsculasEl tema de suscripción debe ir todo en minúsculas
        
      
        QoSSe admiten 0 y 1. QoS 2 necesita un broker dedicado
        
      
        Testamento y sesión persistenteNo están disponibles en el broker compartido
        
      
        Clientes sin actividadSe cierran tras 90 minutos si no reciben paquetes
