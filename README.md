# Ubidots: del sensor al dashboard

Página interactiva del foro **(ABRetos) Investigar que es y la configuración de UBIDOT**.
Universidad Privada Franz Tamayo · Ingeniería de Sistemas · La Paz - Bolivia · 2026

Incluye: qué es Ubidots, dispositivos/variables/dots, configuración en 6 pasos, generador de código HTTP/MQTT/ESP32 y un simulador (dispositivo, red y nube) con dashboard, variable sintética y eventos.

Sitio estático: `index.html`, `style.css`, `app.js`.
